## 🧑‍💻 About me

- 📊 **Data Analyst at Michelin** (Sales Administration, Rio de Janeiro) — I own the commercial offers structure in **Oracle**, run **SQL/Databricks** pipelines, and replace manual Excel routines with versioned **Python** automation.
- 🎓 **Industrial Engineering @ UNIRIO** — graduating in **December 2026**.
- 🧠 How I work: *understand the process → measure where it breaks → rebuild it in code.* Every automation starts from the business rule, not from the tool.
- 🚀 Currently building **[jpfinanças](https://app.jpfinancas.com.br)** — a personal finance app with natural-language expense entry, written in **Next.js + TypeScript**.
- 🎥 Idealizing **[PO para Todos publisher](https://github.com/jotape-prog22/po-para-todos-publisher)** — a Claude Code pipeline that produces Operations Research lectures for a UNIRIO extension project.
- 🤖 Big fan of **AI-assisted development**: most of my side projects are built with Claude Code in the loop.
